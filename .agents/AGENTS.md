# Regras do Projeto (Financy)

## Estilização e Cores

- **Não utilize cores hardcoded ou valores hexadecimais arbitrários** (ex: `bg-[#f8fafc]`, `bg-[#1c6b43]`).
- **Use sempre os tokens do tema**:
  - `bg-background`, `bg-card`, `bg-muted`
  - `text-foreground`, `text-muted-foreground`
  - `bg-primary`, `text-primary-foreground`, `focus-visible:border-primary`
  - `border-border`, `border-input`
